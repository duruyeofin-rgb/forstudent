## 규칙

- 새 프로젝트는 GitHub가 없어도 된다. **기존 Git 저장소와 원격이 연결된 경우에만** `git fetch`를 한다.
- 처음에는 첫 기능 하나를 완성하고 실제로 작동을 확인한다.
- 요청하지 않은 **기록 저장·교사 대시보드를 자동 생성하지 않는다**.
- 기록을 서버에 저장한다면 학생·교사 신원 검증, 권한 분리, 보관·삭제를 검증한다. **학급 코드+번호만으로 인증이 된다고 단정하지 않는다.**
- 비밀값은 채팅·Git·로그·브라우저 코드에 출력하지 않는다.
- 유료 사용·운영 DB 변경·되돌릴 수 없는 삭제·배포는 먼저 승인받는다.
- 기존 기능·문항·보상·기록을 보존하고, 변화 시 관련 문서를 갱신한다.
