# 01. 네 가지 질문 해설과 예시

0단계에서 던지는 네 질문은 선생님의 교실을 앱 설계로 옮기는 입구입니다. 이 파일은 (1) 각 질문의 의도, (2) 좋은 답과 되묻는 법, (3) 교과별 예시, (4) 기획 요약 양식을 담고 있습니다. 선생님이 "예시 보여 줘"라고 하거나 답이 모호할 때 읽으세요.

## 질문 1. 학생의 배움이 멈추는 순간은 언제입니까?

**의도**: 앱이 풀어야 할 문제를 하나로 좁힙니다. 이 답이 학습 흐름(힌트·재도전), 저장할 기록, 교사 화면의 "먼저 살펴볼 학생" 기준을 모두 정합니다.

멈춤의 모양은 여러 가지입니다. 어느 쪽인지 알아야 처방이 달라집니다.

| 멈춤의 모양 | 앱의 처방 |
|---|---|
| 모른다 (내용) | 짧은 설명 + 소리·그림 힌트 |
| 방법을 모른다 | 첫 화면의 한 가지 행동 안내, 예시 |
| 틀릴까 봐 두렵다 | 벌점 없음, 힌트 후 다시 해 보기 |
| 틀렸는데 아무도 모른다 | 첫 시도 기록 + 교사 화면에서 반복 오류 표시 |
| 선생님 도움을 기다린다 | 확인 대기 목록, 교사가 통과·넘어가기 |
| 지루하다 | 활동 모양 바꾸기, 짧은 단위, 의미 있는 보상 |
| 기기·로그인이 어렵다 | 로그인 없는 입장(학급 코드+번호) |

**좋은 답의 예**
- "겹받침이 있는 글자(닭, 읽다)에서 소리 내지 못하고 그냥 넘어갑니다."
- "문제를 틀려도 선생님이 학생 25명을 한꺼번에 못 봐서, 고치지 못한 채 다음 단원으로 갑니다."

**약한 답과 되묻기**
- "공부를 싫어해요" → "그 순간 학생이 무엇을 하고 있나요? 어느 활동에서 멈추나요?"
- "집중을 못 해요" → "언제(수업 중/숙제), 어떤 활동에서 그런가요? 하나만 고른다면요?"

**후속 질문 (필요할 때 최대 두 개)**: 누가(몇 명, 어떤 학생)? 멈추면 어떻게 되나요(넘어감/포기/질문)? 지금은 어떻게 도와주고, 그 순간을 어떻게 알게 되나요?

## 질문 2. 학생이 가장 먼저 해야 할 일은 무엇입니까?

**의도**: 첫 화면과 입장 방식을 정합니다. 앱이 열렸을 때 학생 앞에 놓일 일은 **한 가지**여야 하고, 10초 안에 시작할 수 있어야 합니다. 학년이 낮을수록 입력(글자 치기, 계정 만들기)이 첫 장벽이 됩니다.

**좋은 답의 예**
- "자기 번호를 누르고, 오늘 낱말 5개를 소리 내어 읽습니다."
- "문제를 보고 답을 터치합니다."

**후속 질문**: 어떤 기기를 쓰나요(태블릿 가로/PC/휴대폰)? 한 기기를 여럿이 번갈아 쓰나요(→ 이전 학생이 열리지 않게 항상 처음부터 입장)? 인터넷은 안정적인가요? 학생이 글자를 읽을 수 있나요(→ 소리 안내)? 한 반 인원은?

## 질문 3. 웹앱 또는 도구로써 구현하고 싶은 기능은 무엇입니까?

**의도**: 첫 버전의 범위를 정합니다. 선생님이 말한 기능을 모두 만들지 않고, **가장 필요한 하나**를 끝까지 만든 뒤 늘립니다. 기능마다 "이 기능이 1번 질문의 멈춤을 어떻게 풀어 주는가?"를 한 줄로 적습니다. 대답하지 못하는 기능은 '나중에'로 보냅니다.

분류 양식:
- **필수** (이게 없으면 앱이 의미 없음)
- **있으면 좋음**
- **나중에**

**후속 질문**: 하나만 고른다면 무엇인가요? 선생님이 화면에서 보고 싶은 것은 무엇인가요(누가 어려워하는지/진도/제출 여부)? 학생이 얻는 것은 무엇인가요(피드백/보상)? 입력 방식은(터치/타자/말하기)? 한 번에 몇 분 쓰나요?

## 질문 4. 웹앱에 들어가서는 안되는 정보는 무엇입니까?

**의도**: 저장하지 않을 항목을 처음에 정합니다. 선생님이 직접 말한 것 외에 `03-privacy-and-safety.md`의 **기본 금지 목록**을 함께 제안하고 확인받습니다.

**좋은 답의 예**
- "학생 이름, 사진, 연락처."
- "성적을 학생끼리 비교하는 화면."

**후속 질문**: 학교나 교육청의 정보 보호 지침이 있나요? 보호자 동의가 필요한가요? 앱에서 나온 자료(CSV 등)를 학급 밖으로 내보내나요? 학년이 끝나면 기록을 어떻게 하고 싶은가요?

## 교과별 예시

| | 국어(받침 읽기) | 수학(곱셈 연습) | 영어(단어) | 독서 |
|---|---|---|---|---|
| 1. 멈춤 | 겹받침 글자를 읽지 못하고 넘어감 | 곱셈구구 7단에서 막혀 포기 | 철자를 틀렸는데 모르고 외움 | 읽고 무슨 내용인지 말 못함 |
| 2. 첫 일 | 번호를 누르고 낱말 읽기 | 번호를 누르고 문제 1개 풀기 | 번호를 누르고 단어 듣기 | 번호를 누르고 책 고르기 |
| 3. 기능 | 듣고 고르기, 교사 피드백 | 자동 출제, 틀린 구구 모아 복습 | 철자 맞히기, 날짜별 복습 | 한 문장 요약 쓰기, 교사 확인 |
| 4. 금지 | 이름, 목소리 녹음 | 이름, 점수 순위 | 이름, 사진 | 이름, 가정 이야기가 담긴 글 |

## 기획 요약 양식 (5줄)

질문 답을 받으면 아래 다섯 줄로 줄여서 "이렇게 이해했는데 맞나요?"라고 확인합니다.

1. **멈추는 순간**: …
2. **학생의 첫 행동 / 첫 화면**: …
3. **첫 버전 기능 (하나)**: … (나중에: …)
4. **넣지 않을 정보**: …
5. **선생님이 10~20초 안에 알 수 있어야 하는 것**: … (예: 오늘 누가 어떤 낱말에서 막혔는지)

5번은 선생님이 직접 답하지 않았어도 1~3번에서 추려 제안합니다. 이것이 완성 여부를 가리는 성공 기준이 됩니다.
