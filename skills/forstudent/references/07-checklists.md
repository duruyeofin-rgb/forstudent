# 07. 점검표

단계마다 복사해서 쓰는 목록입니다. 체크는 **실제로 확인한 것**만 합니다.

## A. 기획 확인 (0~2단계 끝)

- [ ] 네 질문의 답이 있다 (이미 대화에 있으면 요약으로 확인받았다)
- [ ] 5줄 기획 요약을 선생님이 확인했다
- [ ] 금지 목록이 있다 (선생님 답 + 기본 금지 목록)
- [ ] 첫 버전 기능이 **하나**로 정해졌다. 나머지는 '나중에'로 분류했다
- [ ] 기록을 남겨서 교사가 봐야 하는지(DB 필요 여부)를 정했다
- [ ] 학생 기기(태블릿/PC), 인터넷 상태, 공용 기기 여부를 알고 있다
- [ ] 유료 사용·운영 DB 변경·배포가 필요한지, 필요하면 승인 방식을 정했다
- [ ] 프로젝트 지침 파일에 저장소·DB·배포 정보 칸이 있다

## B. 개발 중 점검 (단계마다)

- [ ] 빌드와 타입 검사가 통과한다
- [ ] 점검 스크립트(내용·계산·조사·개인정보)가 통과한다
- [ ] 새 기능이 학습 기록(정답률)·보상·진도를 **바꾸지 않는다** (놀이 활동은 별도 기록)
- [ ] 같은 단추 연타, 새로고침, 뒤로 가기에서 중복 저장·중복 지급이 없다
- [ ] 인터넷이 끊겼다가 돌아와도 기록이 남는다
- [ ] DB 표가 아직 없어도 화면이 멈추지 않는다
- [ ] 교사가 초기화한 뒤 학생 기기가 서버 값을 따라간다
- [ ] 문서(README, 프로젝트 지침)가 지금 동작과 맞는다

## C. 학생 화면 점검 (저학년)

- [ ] 한 화면에 한 가지 과제
- [ ] 모든 안내·문제에 🔊 소리 단추가 있다
- [ ] 단추와 글자가 충분히 크다 (태블릿 가로 화면에서 스크롤 없이 한눈에)
- [ ] 틀렸을 때 어디가 틀렸는지 알려 주고, 힌트 후 다시 해 볼 수 있다
- [ ] 벌점·시간제한·순위·실패 화면이 없다
- [ ] 색만으로 정오를 구별하지 않는다
- [ ] 동작 줄이기 설정에서 애니메이션이 멈춘다
- [ ] 조사 오류("이(가)", "을(를)")가 화면에 없다
- [ ] 정답과 똑같이 들리는 오답이 있으면 그림·글자 단서가 있다

## D. 개인정보·접근 통제 (출시 전)

- [ ] 서버에 학생 이름·연락처·사진·음성 원본이 없다 (`privacy-check` 통과 + 직접 확인)
- [ ] CSV 내보내기에 이름이 없다
- [ ] 모든 표에 행 단위 보안(RLS)이 켜져 있다
- [ ] **비로그인** 요청이 모든 표에서 0건이고 쓰기가 거부된다 (실제 요청으로 확인)
- [ ] 학생 A가 **자기 기록**은 읽고 쓸 수 있다
- [ ] 학생 A가 **다른 학생·다른 학급** 기록을 읽거나 쓸 수 없다
- [ ] 교사가 **다른 교사 학급** 기록을 읽거나 쓸 수 없다
- [ ] 서비스 역할 키가 코드·환경 변수·로그·Git 어디에도 없다
- [ ] `.env*`와 배포 도구 설정 폴더가 Git에 올라가 있지 않다
- [ ] 화면에는 공개용 키만 있다
- [ ] 외부 AI·서비스에 학생 입력을 보내지 않는다

## E. 교사 태블릿 검수 (선생님이 직접)

- [ ] 시험용 학급 코드로 입장해서 첫 활동까지 10초 안에 시작된다
- [ ] 이전 학생이 저장된 태블릿에서도 빈 코드 입력부터 시작한다 (공용 기기)
- [ ] 문제를 풀고 틀렸을 때 힌트가 나온다
- [ ] 활동이 끝나면 다음 화면으로 자연스럽게 이어진다
- [ ] 별·보상이 의도대로만 늘어난다
- [ ] 교사 화면에서 방금 한 기록이 보인다 (첫 시도, 틀린 항목)
- [ ] 한 학생만 초기화해 보고, 학생 기기가 처음 화면으로 돌아오는지 본다
- [ ] 소리가 나지 않으면 안내가 나온다 (기기의 한국어 음성 설치 안내)

## F. 배포 후

- [ ] 배포 상태가 준비됨(Ready)이고 공개 주소가 맞다
- [ ] 공개 주소 응답 200, 핵심 화면 동작, 브라우저 콘솔 오류 없음
- [ ] 서버 로그에 오류가 없다
- [ ] DB가 있으면 **새 배포에서** 읽기·쓰기가 이어진다 (시험용 학급)
- [ ] 비밀값이 번들·화면에 노출되지 않았다
- [ ] 기관이 정한 점검 도구가 있으면 실행하고 위험 항목만 고쳤다
- [ ] 결과와 공개 주소를 선생님께 보고했다

## G. 학년 말·방학

- [ ] 학급 기록 삭제 또는 보관 방법을 선생님이 정했다 (README에 절차)
- [ ] 무료 DB 일시정지(7일 미사용) 복구 방법이 README에 있다
- [ ] 새 학년 학급은 새 학급 코드로 만든다
