# 02. 학생 화면과 학습 흐름 설계

초등 저학년(특히 1~2학년)이 혼자 쓸 수 있는 화면을 기준으로 정리했습니다. 학년이 높으면 글자 크기와 설명 길이를 조정하세요. 이유 없이 지키는 규칙은 없으므로 각 항목에 이유를 달았습니다.

## 학생 화면 원칙

| 원칙 | 이유 |
|---|---|
| 한 화면에 한 가지 과제 | 선택지가 많으면 어디를 눌러야 할지 몰라 멈춥니다 |
| 짧고 쉬운 문장, 글자는 크게, 터치 영역은 크게(최소 약 64px) | 손가락이 작고 정확하지 않습니다. 태블릿 가로 화면을 기준으로 설계합니다 |
| 모든 안내와 문제를 소리로 들을 수 있는 🔊 단추 | 글자를 막 배우는 학생이 안내 때문에 막히지 않게 합니다 |
| 틀리면 **어디가 틀렸는지** 짚어 주고, 힌트 후 다시 해 보기 | 정답만 알려 주면 배움이 없습니다. 바로 정답을 선택해 버리게 하지 않습니다 |
| 벌점·시간제한·순위·실패 화면 없음 | 두려움이 멈춤을 만듭니다. 순위는 친구와 비교가 됩니다 |
| 보기를 모두 건드려도 막히지 않음 (세 번 틀리면 설명을 듣고 넘어감) | 학생이 갇히지 않게 합니다 |
| 색만으로 정답·오답을 구별하지 않음 (아이콘·글자 병행) | 색각 차이와 흑백 화면을 고려합니다 |
| 같은 단추를 연타해도 한 번만 처리 | 저학년은 연타합니다. 중복 저장·중복 보상을 막습니다 |
| 동작 줄이기 설정이면 애니메이션 멈춤 (`prefers-reduced-motion`) | 어지럼과 감각 과민을 배려합니다 |
| 효과음이 없어도 이해되게 | 교실은 시끄럽고 소리를 끈 기기도 많습니다 |
| 인터넷이 끊겨도 학습이 이어짐 | 교실 와이파이는 불안정합니다 (`04-architecture.md`의 오프라인 저장) |

## 학습 흐름 패턴

- **단원 → 연습 → 확인 → 다음 단원**: 단원을 작게 나누고, 첫 시도에 80% 이상 맞히면 통과로 하되 기준은 한 곳에서 바꿀 수 있게 합니다. 틀린 문제만 다시 풀게 합니다.
- **첫 시도와 재시도를 구분해서 기록합니다.** 첫 시도 결과가 학생이 정말 아는지를 보여 주고, 재시도는 고쳐 푸는 힘을 보여 줍니다. 이 구분이 성장 분석의 바탕입니다 (`06-teacher-dashboard.md`).
- **단원 순서를 바꾸지 않습니다.** 수업이 시작된 뒤에 문항 순서나 번호를 바꾸면 저장된 기록의 문항 번호와 어긋납니다. 추가는 뒤에만 합니다.
- **복습**: 한 번 배우고 끝내지 않고 다음 날·3일 뒤·일주일 뒤에 다시 만나게 합니다. 어려워한 것은 다음 날 먼저 다시 냅니다. 늦게 접속해도 같은 날 여러 회차를 한꺼번에 열지 않습니다.
- **깊이 익히기**: 같은 내용을 고르기 → 빈칸 채우기 → 소리 내어 읽기 → 이야기 이해처럼 활동 모양을 바꿔 가며 익히게 합니다. 한 가지 모양만 반복되면 2~3주째에 질립니다.
- **한 번에 5~10분**: 단위를 짧게 유지하고 쉬었다 이어갈 수 있게 합니다.

## 보상 설계

- **보상은 학습 뒤에 옵니다.** 학습이 먼저이고 게임은 뒤입니다. 보상을 얻으려고 학습을 건너뛰게 만들면 목적이 무너집니다.
- **별은 돈이 아니라 모으는 것**입니다. 쓰면 줄어드는 재화나 상점은 만들지 않습니다. 정해진 조건이 채워지면 의미 있는 것(예: 내가 고른 직업의 세계)이 하나씩 열립니다.
- **조건을 보여 줍니다**: "다음까지 별 5개"처럼 학생이 목표를 알 수 있게 합니다.
- **놀이 활동의 결과는 학습 기록과 섞지 않습니다.** 미션·게임에서 맞힌 것을 정답률에 더하면 성장 추세가 왜곡됩니다. 별도 표에 저장하고 교사 화면에서 따로 보여 줍니다. 별도 보상을 주더라도 기존 별은 더하지 않습니다.
- 보상은 서버에서 한 번만 지급합니다 (중복 클릭·재접속·다른 기기로 다시 받지 못하게).

## 문항과 피드백

- **내용은 한 곳에 모읍니다** (예: `curriculum.ts`). 낱말·문장·정답·발음을 이 파일에서만 고치게 하고, 점검 스크립트가 이 파일을 검사합니다.
- **오답 보기는 '배운 규칙에서 헷갈리기 쉬운 것'**으로 만듭니다. 아무 엉뚱한 보기를 넣으면 맞히기 쉽고 배움이 없습니다.
- **정답과 똑같이 들리는 오답이 있으면 소리만으로 구별하게 하지 않습니다.** 그림, 글자 모양 강조, 뜻 단서를 함께 줍니다.
- 피드백은 짧게, **핵심 부분을 색과 크기로 강조**합니다 (예: 받침 글자).
- 아직 배우지 않은 내용은 맞춤 문항으로도 앞당겨 내지 않습니다.
- 교육과정의 표기·발음 데이터를 임의로 바꾸지 않고, 새 낱말이 필요하면 검토 대상으로 제안만 합니다.

## 한국어 문장 품질

- "의사이(가) 되었어요", "을(를)", "(으)로" 같은 표기는 학생에게 보이지 않게 합니다. 낱말 끝 글자의 받침 유무로 조사를 고르는 작은 함수(`이/가`, `을/를`, `은/는`, `으로/로`, `이에요/예요`)를 만들어 쓰고, 점검 스크립트가 소스에서 이런 표기를 찾으면 실패하게 합니다.
- 안내 문구는 한 곳에 모아 두고 조사 오류가 없는 고정 문장으로 씁니다.

## 그림

- 그림체를 통일합니다 (캐릭터·배경·소품이 같은 느낌). 이모지 중심 화면이나 스타일이 다른 그림을 섞지 않습니다.
- **문자와 문제 보기는 그림 안에 넣지 않고** 화면의 글자로 그립니다 (그림 속 글자는 틀리기 쉽고 고칠 수 없습니다).
- 배경은 가로형, 오브젝트는 투명 배경 WebP로 최적화합니다.
- AI 이미지 생성은 **유료**입니다. 먼저 장수와 예상 비용을 알리고, 소량으로 시험한 뒤 늘립니다. 그림이 없는 자리는 눈에 띄는 임시 그림으로 두고 필요한 그림 목록을 남깁니다 (임시 그림을 완성품처럼 두지 않습니다).
- 아직 얻지 않은 보상 그림을 다른 화면에서 미리 보여 주거나 보유 상태를 바꾸지 않습니다.
